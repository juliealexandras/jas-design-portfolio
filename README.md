# 👾 Julie's Design Portfolio 👾

Personal site for product design work: past work highlights, about, and a playground for experiments. Built with Next.js, TypeScript, and Tailwind CSS.

## Features✨

- Responsive layout for desktop and mobile
- Work, About, and Playground pages
- Site copy centralized in one file (`lib/content.ts`)
- Dark mode — *coming soon*

## Tech stack✨

- Next.js 16 and React 19
- TypeScript
- Tailwind CSS 4
- Vercel

## Project structure✨

```
app/            Routes and pages (Work, About, Playground)
components/     Shared UI (chrome, cards, social links)
lib/content.ts  Visitor-facing copy — names, projects, bio
public/         Static assets
```

Edit strings in `lib/content.ts` instead of hunting through components.

## Getting started✨

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The site updates as you edit.
